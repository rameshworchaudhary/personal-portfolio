# Rameshwor Chaudhary Portfolio

A modern interactive portfolio showcasing the work, projects, research, and technical skills of **Rameshwor Chaudhary**.

## Overview

This project is a handcrafted portfolio built using **HTML, CSS, and Vanilla JavaScript** with a lightweight **Node.js + Express** backend for AI functionality.

The website highlights projects, skills, education, achievements, and research while providing visitors with an interactive AI-powered experience.

# AI Voice Assistant

The portfolio contains an AI Voice Assistant named **Ishwor**.

Capabilities include:

* Answering questions about Rameshwor Chaudhary
* Explaining projects
* Discussing skills
* Explaining research
* Speaking responses using Text-to-Speech
* Understanding English, Hindi, and Hinglish
* Providing concise conversational answers

---

# Backend

The backend securely communicates with the Groq API.

The API key must remain server-side and should never be exposed to the frontend.

Environment variables are loaded using `.env`.

Example:

```env
GROQ_API_KEY=your_groq_api_key
PORT=3000
```

# Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

---

# Deployment

This project is intended to run on:

* Vercel (recommended)
* Node.js hosting platforms

The frontend is static, while the AI backend requires a Node.js runtime.

GitHub Pages can host the static frontend only and cannot execute the backend.

# Important Development Rules

When modifying this project:

* Preserve the existing portfolio design.
* Preserve all animations.
* Preserve all layouts.
* Preserve all sections.
* Preserve responsiveness.
* Preserve existing JavaScript functionality.
* Do not redesign the website.
* Do not migrate the project to React or Next.js unless explicitly requested.
* Keep the project lightweight.
* Keep the AI backend secure.
* Never expose API keys.
* Make minimal code changes whenever possible.
